# 🎓 University Management System (UMS) — Project Showcase

> **Note:** This repository is a technical portfolio showcase. The source code is proprietary and kept in a private repository.

---

## 📌 Executive Summary
A comprehensive, enterprise-level University Management System designed to streamline academic administration, student registration, course scheduling, and grade processing. Built with scalability, data integrity, and high performance in mind.

---

## 🛠️ Tech Stack & Architecture

| Layer | Technology Used |
| :--- | :--- |
| **Backend / Logic** | Java / JavaScript / CSS / HTML |
| **Database** | MySQL |
| **Architecture** | Modular Microservices |
| **Authentication** | Role-Based Access Control (RBAC) |

---

## ✨ Key Features & Modules

### 👨‍🎓 1. Student Portal
* Course registration & enrollment management.
* Real-time GPA/CGPA calculator & academic history.
* Schedule generator with time-conflict detection.
* View Study Planner.
* View Assignments and Submitting Tasks.
* View Attendance.
* View Academic Calendar.
* Viwe Financial matter.
* View exam schedules for the courses.
* View and edit some info in Profile.
* Generate PDFs for all needs.

### 👨‍🏫 2. lecturer Portal
* View the lessons they teaches.
* Grade submission & approval workflows.
* Assign students Attendance.
* View Academic Calendar.
* View Financial Statements
* View and edit some info in Profile.
* Generate PDFs for all needs.

### 🏛️ 3. Administrative Dashboard
* User management with granular permissions (Administrators, Student, Lecturers).
* ACADEMIC OPERATIONS manage (Colleges, Majors, Courses, Academic Calendar, Department Settings).
* Assign Study Planner.
* Attendance reports.
* Manage Academic Calendar.
* Complete archiving for (students, attendees, administrators, and staff).
* Automated report generation (Transcripts, Enrollment Stats).
* ALL Financial income, expenses, Assign tuitions & tuitions tracking, and generating Excel files.
